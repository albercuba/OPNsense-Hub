Secure connector for {{ device.hostname }}

The connector keeps the browser-to-firewall TLS stream encrypted while it crosses the Hub. The Hub forwards ciphertext and never receives the OPNsense administrator password.

1. Start the local connector

python3 connector/opnsense_hub_connector.py --hub-url {{ connector_hub_url }} --device {{ device.id }} --listen 127.0.0.1:{{ connector_local_port }}

The command prompts for the token without displaying it.

2. Copy the short-lived connector token

This token expires in {{ connector_session_ttl_minutes }} minutes and is stored only as a hash by the Hub.

3. Open the local endpoint

Open OPNsense through the connector

The OPNsense WebGUI certificate must be trusted by the browser. For an exact hostname match, map the firewall certificate hostname to 127.0.0.1 and pass it with --browser-host.
